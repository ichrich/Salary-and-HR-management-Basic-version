# 1С:ЗУП Базовая

Страница для GitHub Pages: `index.html`. Публикуйте содержимое этого репозитория целиком, включая `assets`, `reference`, CSS и JS. В Settings → Pages выберите публикацию из нужной ветки, папка `/ (root)`.

Все локальные ресурсы лежат внутри репозитория. Хедер, меню и футер исключены из страницы и сборки по запросу; содержимое посадочной сохранено. Корзина использует существующий сайт компании, GitHub Pages не обрабатывает заявки самостоятельно.

В исходном рабочем проекте пересобрать страницу можно командой `node zup-basic/build-preview.mjs`. Для публикации готового `index.html` сборка не требуется. Демо сохраняет `noindex,nofollow`, чтобы не конкурировать с основной страницей в поиске.
